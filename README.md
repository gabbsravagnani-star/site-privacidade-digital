# Privacidade Digital e Proteção de Dados Pessoais

Site educativo de página única em HTML, CSS e JavaScript. O quiz tem cinco perguntas. As respostas e a pontuação ficam na memória da página e são descartadas quando você a recarrega.

## Abrir no VS Code

1. Extraia o ZIP para uma pasta.
2. No VS Code, escolha **Arquivo → Abrir Pasta** e selecione a pasta que contém `index.html`.
3. Abra `index.html` no navegador pelo Explorador de Arquivos. O site funciona localmente, sem instalação. Os links das fontes abrem páginas externas.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub e envie `index.html`, `style.css`, `script.js`, a pasta `assets` e este README para a raiz do branch `main`.
2. Acesse **Settings → Pages**. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Selecione `main` e `/(root)`. Clique em **Save** e aguarde o endereço aparecer em **Settings → Pages**.

[Guia oficial de configuração do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
